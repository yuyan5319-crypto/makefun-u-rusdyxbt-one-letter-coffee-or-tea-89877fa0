One letter, one answer: **A — coffee**. Written for the
[make.fun bounty](https://make.fun/bounty/u-rusdyxbt-one-letter-coffee-or-tea-89877fa0).

Coffee wins the argument the way it wins most mornings: louder, bolder,
and impossible to ignore. Tea whispers; coffee shows up.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (it runs TypeScript as-is). It validates the
letter (exactly one non-whitespace character), writes it to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), sets the file mode
to 0644, and reads it back to verify it matches exactly.
